# Business Operations Portfolio
## 데이터를 운영 기준과 실행으로 연결하기
카페 현장의 주문·재고·정산 개선, 교내 행사 운영, 다국적 팀 시장분석, 레시피 서비스 데이터 구축 경험을 Business Operations Manager 지원 관점으로 정리했습니다.

이 포트폴리오는 **사용자가 과거 채팅에 직접 작성한 경험**을 바탕으로 합니다. 회사 차원의 운영 총괄, 정식 Manager 재직 경력을 주장하지 않습니다. 카페명과 경험 발생 연월은 확인되지 않아 기재하지 않았습니다.

## How to read
각 case study는 상황 → 역할 → 판단·행동 → 결과 → 측정 한계 순서로 구성했습니다.
- [Metrics & definitions](METRICS.md): 수치의 의미와 비교 가능 범위
- [Skills mapping](SKILLS.md): 실제 행동과 지원 직무 역량 연결
- [Evidence register](EVIDENCE.md): 사용자 작성 기록의 출처와 발췌
- [Reporting example](examples/README.md): 확인된 집계 수치를 읽는 간단한 코드

## Evidence boundary
성과는 사용자 서술 기준이며 원본 POS, 설문, 정산 자료로 독립 검증한 결과는 아닙니다. 원자료, 고객정보, 회사 내부 파일은 포함하지 않았습니다. 지원 기업명과 지원 마감일은 근무 회사·재직 기간으로 전환하지 않았습니다. 새로 작성한 문서·코드는 이번 포트폴리오 정리 산출물이며 과거 실무 산출물로 제시하지 않습니다.
