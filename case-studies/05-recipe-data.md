# 레시피 데이터 수집·구조화와 서비스 연결
**경험 유형:** AI·빅데이터 교육 관련 팀 프로젝트 / **출처:** E5 / **기간·기관:** 미확인

## 수행 내용
웹 크롤링으로 레시피 300개를 수집하고 재료, 조리 과정, 레시피 정보를 서비스에 사용할 수 있게 정제·구조화했습니다. MariaDB와 연결해 사용자가 보유한 식재료로 레시피를 탐색하는 데이터 흐름을 구축했습니다.

사용자 보유 재료 기반 추천 로직과 REST API를 구현했습니다. Spring Boot으로 사용자·식재료·레시피 데이터를 연결하고 JWT 인증을 적용했습니다. React에서 재료 등록·추천 결과·상세 화면을 구성하고 API와 연동했습니다.

## Business Operations 연결
운영에서 사용할 수 있는 데이터 형식을 마련하고 수집부터 서비스 활용까지 연결한 경험입니다. 위 기술은 사용자가 직접 작성한 구현 경험이며, 원본 코드를 이번 작업에서 검증한 것은 아닙니다.

## 확인 범위
정량 근거는 수집 레시피 300개입니다. 추천 정확도, 사용자 수, 오류 감소율, 처리시간 절감은 기록으로 확인되지 않아 기재하지 않았습니다. 원본 코드가 없어 이 저장소에는 당시 구현을 복원한 코드나 가상 레시피 데이터를 넣지 않았습니다.
