# 확인된 집계 수치의 보고 예시
이 폴더의 CSV는 METRICS.md에 있는 실제 서술 수치만 옮긴 집계 데이터입니다. 원본 거래·설문 데이터가 아닙니다.

report_metrics.py는 이번 포트폴리오를 위해 새로 작성한 표준 라이브러리 코드입니다. 과거 업무에 사용한 코드나 당시 자동화 성과로 제시하지 않습니다.

실행: `python examples/report_metrics.py`

정확히 비교 가능한 입고 확인 시간만 차이를 계산합니다. 대기시간의 “4분대”, 폐기율의 “미만”, 회차별 목표 매출 달성률은 임의의 정확한 값이나 매출 성장률로 변환하지 않습니다.
